Pre-flight checklist

  • Code is pushed to a GitHub (or GitLab) repository that Render/Vercel can access.
  • You have a Gemini API key from aistudio.google.com.
  • You have a Render account and a Vercel account (both free).

Part 1 — Deploy Backend to Render Render · free tier

Render will build your Docker image and run it as a Web Service. The free tier spins down after 15 minutes of inactivity — the first request after that will be slow (~30 s). Upgrade to a paid instance to avoid cold starts.

1Go to render.com → New → Web Service. Connect your GitHub/GitLab account and select the repository.
2 Fill in the service settings:
  • Name: testgen-ai-backend (or any name you like)
  • Root Directory: backend
  • Runtime: Docker — Render detects the Dockerfile automatically
  • Region: pick the closest to your users
  • Instance Type: Free
3Under Environment Variables, add the following:
VariableValueRequired?
GEMINI_API_KEY Your Gemini API key (from aistudio.google.com) Required
ALLOWED_ORIGINS Your Vercel frontend URL — e.g. https://testgen-ai.vercel.app
Add after the frontend is deployed. Can be a comma-separated list.		 Required
PORT Render injects this automatically — do not set it manually. Auto-set
4Click Create Web Service. Render builds the Docker image and deploys it. Wait for the status to show Live.
5Copy your service URL — it looks like https://testgen-ai-backend.onrender.com. You'll need it for the frontend step.
6Verify the API is up: open https://<your-service>.onrender.com/health in a browser — you should see {"status":"ok"}.
Note on cold starts: If you're demoing the app, hit /health in your browser ~30 seconds before so the instance is warm.

Part 2 — Deploy Frontend to Vercel Vercel · hobby (free)

Vercel detects the Vite project, runs npm run build, and serves the dist/ output as a global CDN.

1Go to vercel.com → New Project. Import your repository.
2 Configure the project:
  • Framework Preset: Vite (auto-detected, or select manually)
  • Root Directory: frontend
  • Build Command: npm run build (default)
  • Output Directory: dist (default)
  • Install Command: npm install (default)
3Under Environment Variables, add:
VariableValueRequired?
VITE_API_BASE_URL Your Render backend URL — e.g. https://testgen-ai-backend.onrender.com (no trailing slash) Required
4Click Deploy. Vercel installs dependencies, runs vite build, and publishes the dist/ folder.
5After the deployment succeeds, note your Vercel URL — e.g. https://testgen-ai.vercel.app.
6Go back to Render and update the ALLOWED_ORIGINS environment variable to your Vercel URL. Render will redeploy automatically.

Local development (after deployment setup)

Backend

  1. Copy backend/.env.example → backend/.env and fill in your GEMINI_API_KEY.
  2. Set ALLOWED_ORIGINS=http://localhost:3000 in backend/.env.
  3. Run: cd backend && uvicorn app.main:app --reload --port 8000

Frontend

  1. Copy frontend/.env.example → frontend/.env.
  2. Leave VITE_API_BASE_URL unset (or set it to http://localhost:8000) — the config falls back automatically.
  3. Run: cd frontend && npm run dev

Redeploying after code changes

  • Render: every push to your default branch triggers an automatic Docker rebuild and redeploy.
  • Vercel: every push triggers a new build. Pull-request branches get preview URLs automatically.
  • If you update ALLOWED_ORIGINS on Render, trigger a manual redeploy via the dashboard (or push any commit).
